Frequently Asked Questions

Does StoreMate Pro require external SaaS API keys or monthly subscriptions? +
No. StoreMate Pro runs 100% natively on your WordPress host. It does not ping third-party paid servers or require monthly credits. You own the code and run unlimited imports.
Will my server get IP-blocked by Amazon or AliExpress? +
StoreMate Pro uses randomized browser fingerprints and rotating User-Agents with stealth headers to mimic human browser traffic. It avoids aggressive concurrent scraping, ensuring consistent 200 OK responses.
Is it compatible with Rank Math and Yoast SEO? +
Yes. StoreMate Pro automatically synchronizes with both Rank Math and Yoast SEO. It automatically fixes broken column layouts on the Products list and injects pristine Schema.org JSON-LD structured data.
What are the server requirements? +
Standard WordPress hosting running PHP 7.4 to 8.3 with cURL and DOM extensions enabled (active on 99.9% of hosts) and WooCommerce 6.0+.
